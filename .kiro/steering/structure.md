# Structure Steering — Nezha Cyber (哪吒网络安全)

> Canonical specification / 权威规范: [`AGENTS.md`](../../AGENTS.md) (English) | [`AGENTS_ZH.md`](../../AGENTS_ZH.md) (简体中文)

## Layered Architecture / 分层架构
```text
[ Presentation & Entry Layer ]  MainMenu (7 styles) · src/core/menu_items/* · serial_commands/* · WebUI
              │
[ Feature Modules Layer ]       src/modules/{wifi,ble,rf,ir,rfid,lora,wire,others/*}
              │
[ Core OS & Services Layer ]    display · theme · i18n · config · configPins · sd_functions · radio_mem · location_state
              │
[ Bus & Hardware HAL Layer ]    bus_HAL (I2CLease / acquireSPIBus) · boards/<board>/interface.cc · lib/HAL
```

- **Direction of Dependencies**: Menus/CLI/WebUI call into Feature Modules and Core OS; Feature Modules call Core OS and Bus HAL; Core OS must **not** pull heavy feature-module headers into global headers (`include/globals.h`, `src/core/radio_mem.h`).
- **Shared Logic Across GUI & CLI**: Parsing, RF/RFID encoding, and protocol execution belong in `src/modules/` or `src/core/` so TFT menus (`src/core/menu_items/`) and Serial CLI (`src/core/serial_commands/`) share one implementation and never diverge.

## Repository Directory Map / 目录结构
- `src/main.cc` — Boot pipeline (`_setup_gpio` → TFT/Splash → `_pre_storage_gpio` → FS/Config → `_post_setup_gpio` → `taskInputHandler` → `mainMenu.begin()`), SPI host setup, main loop.
- `src/core/` — Core OS: `display.*`, `theme.*`, `settingsColor.h`, `i18n.*`, `lang_zh_cn.h`, `cjk_font_data.h` (autogenerated), `config.*`, `configPins.*`, `bus_HAL.*`, `sd_functions.*`, `main_menu.*`, `radio_mem.h`, `ram_profile.*`, `location_state.*`, `scrollableTextArea.*`, `menu_items/`, `serial_commands/`, `tftLogger/`, `wifi/`.
- `src/modules/` — Feature domains (`wifi/`, `ble/`, `rf/`, `ir/`, `rfid/`, `lora/`, `wire/`, `others/` including `nezha_pet.*`, `radar.*`, `flipper_tools.*`, `qrcode_menu.*`).
- `boards/<board>/` — Board `.ini` + `interface.cc` implementing `include/interface.h` hooks (`_setup_gpio`, `_pre_storage_gpio`, `_post_setup_gpio`, `InputHandler`, `getBattery`, `isCharging`, `_setBrightness`, `powerOff`, `goToDeepSleep`, `checkReboot`).
- `include/` — Shared contracts (`globals.h`, `interface.h`, `MenuItemInterface.h`, `DisplayDrivers_User_Setup.h`, `precompiler_flags.h`).
- `partitions/` — Custom 4 MB / 8 MB / 16 MB partition CSV tables.
- `embedded_resources/` — WebUI assets (gzipped into gitignored `include/webFiles.h`).
- `scripts/build/` & `tools/` — PlatformIO SCons hooks and host scripts (`gen_cjk_font.py`, `gen_mfcodes.py`).

## Anti-Slop & Code Style Rules / 零垃圾代码与风格
1. **Read before writing**: Inspect real files before editing; never hallucinate pins, macros, headers, or APIs.
2. **Minimal scoped diffs**: Modify only files required by the task. No drive-by refactors, no stubs/`TODO`s, no mocked telemetry.
3. **Formatting**: `.cc` / `.h` follow `.clang-format` (LLVM, 4 spaces, 110 cols, attached braces, `IndentCaseLabels: true`).
4. **Clean tree**: Never commit `NezhaCyber-*.bin`, `.pio/`, `__pycache__/`, `include/webFiles.h`, `include/current_year.h`, or `compile_commands.json`.
5. **Git**: Branch off `development` (`feat/*`, `fix/*`, `ui/*`, `i18n/*`, `docs/*`, `chore/*`) with atomic Conventional Commits; all PRs must target `development` (maintainer promotes `development` → `main`).
